Q1

The Personalized System of Instruction (PSI) was developed by:

A. Fred S. Keller
B. B. F. Skinner
C. Robert Gagné
D. Benjamin Bloom

✅ Official Answer: A — Fred S. Keller

Q2

In the Indian context, flipped classrooms align well with:

A. Gurukul system
B. e-learning platforms
C. Traditional chalk-and-talk
D. Examination reforms only

✅ Official Answer: B — e-learning platforms

Q3

Using YouTube tutorials to learn skills is an example of:

A. Formal mobile learning
B. Work-based learning
C. Informal mobile learning
D. Context-aware learning

✅ Official Answer: C — Informal mobile learning

Q4

The future of blended learning is expected to be strengthened by:

A. Printed textbooks
B. Chalk-and-talk method
C. Annual examinations
D. AI, VR, and AR

✅ Official Answer: D — AI, VR, and AR

Q5

In a flipped classroom, instructional content is delivered:

A. Before class resources
B. During class lectures
C. Through group discussion
D. Only through textbooks

✅ Official Answer: A — Before class resources

Q6

Learning Management Systems (LMS) are mainly used to:

A. Replace teachers
B. Conduct final exams
C. Personalize learning
D. Increase workload

✅ Official Answer: C — Personalize learning

Q7

The key feature that distinguishes mobile learning from e-learning is:

A. Multimedia use
B. Online content
C. Teacher supervision
D. Mobility of the learner

✅ Official Answer: D — Mobility of the learner

Q8

Which learning theory strongly supports flipped classrooms?

A. Constructivism
B. Behaviourism
C. Associationism
D. Connectionism

✅ Official Answer: A — Constructivism

Q9

Which of the following is the core principle of PSI?

A. Group learning
B. Fixed schedule
C. Mastery learning
D. Competitive ranking

✅ Official Answer: C — Mastery learning

Q10

The Flipped Classroom belongs to which blended learning model?

A. Flex model
B. Rotation model
C. Self-blended model
D. Enriched virtual model

✅ Official Answer: B — Rotation model
